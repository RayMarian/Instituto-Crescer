Instituto Crescer

Projeto desenvolvido como atividade acadêmica do curso de Análise e Desenvolvimento de Sistemas (ADS).

📌 Sobre o projeto

O Instituto Crescer é um projeto de site desenvolvido para representar uma organização voltada para ações sociais, apresentando informações sobre seus projetos e formas de participação.

O objetivo é aplicar na prática conceitos de desenvolvimento web, organização de código, responsividade, acessibilidade e controle de versões.

🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

✨ Funcionalidades

- Navegação entre as seções do projeto
- Apresentação das informações do Instituto
- Página de projetos
- Formulário de cadastro
- Layout responsivo
- Validação de formulário com JavaScript

🎓 Projeto acadêmico

Este projeto foi desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas, com o objetivo de colocar em prática os conhecimentos adquiridos ao longo da disciplina.
